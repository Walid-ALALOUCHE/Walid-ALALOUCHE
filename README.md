### About me

I'm a final-year engineering student specializing in **Artificial Intelligence and Digital Trust**, currently interning at **ELAVI** on **Flugia**, a multi-agent AI orchestration platform. My work sits at the intersection of applied AI (LLM tool-calling agents, real API integrations) and application security — I'm particularly interested in the security and reliability challenges specific to AI-agent-powered backends, an area that's still fairly under-tooled.

I'm currently looking for a **6-month PFE internship**, starting January/February 2027, in AI or Software Engineering R&D.

### 🔭 What I'm working on

- Building and hardening AI agents within a production multi-agent platform (backend: Python/FastAPI, frontend: Next.js/React/TypeScript)
- **[Agent Sentinel](https://github.com/Walid-ALALOUCHE/agent-sentinel)** — a standalone security scanner for LLM-agent backends: tenant isolation, confirmation-bypass, auth, and file-exposure testing, with real adversarial test suites (concurrency races, session hijacking attempts, token theft)
